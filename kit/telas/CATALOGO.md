# Catálogo de telas do Moove

Capturas reais do sistema com dados de demonstração (Aurora Serviços, Horizonte Comercial, Vértice Consultoria, Construtora Crescer, X Financeira, Consultoria Fleury). Recebidas em 29/10/2026.
Uso no kit: slide `"tipo": "tela"` com `"tela": "<arquivo>"`. Telas terminadas em `-m` são de celular (moldura de celular); as demais, de computador (moldura de notebook). `"recorte": [x0, y0, x1, y1]` (frações de 0 a 1) amplia um trecho.

**Regras:** não usar `usuarios.webp` nem `permissoes.webp` (mostram e-mails reais da equipe); `etica*.webp` só em post sobre canal de ética, deixando claro que o caso é fictício; nunca apresentar números das telas como resultado real de cliente.
