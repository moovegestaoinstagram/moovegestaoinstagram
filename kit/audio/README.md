# Trilhas para Reels

Coloque aqui só faixas com licença que permite uso comercial em redes sociais, sem custo
(ex.: Biblioteca de Áudio do YouTube com "atribuição não obrigatória", Pixabay Music, CC0 do Openverse/Freesound).
Para cada arquivo, acrescente uma linha em `licencas.csv` com: arquivo, título, autor, fonte (URL), licença, data do download.

Preferência: áudio nativo do Instagram (via Metricool `audioConfiguration`, exige a conta ligada a uma Página do Facebook),
porque músicas em alta ajudam a distribuição. Sem página ligada, use estas faixas em volume baixo (-18 LUFS) sob o texto.
